# 📚Библиотека

Многостраничное приложение для управления библиотекой с ролями читателя и библиотекаря.

## Стек
- HTML, CSS (адаптив)
- TypeScript, JavaScript
- Node.js + Express (бэкенд)
- PostgreSQL
- SVG (интерактивная карта)

## Основной функционал

- Каталог с поиском и фильтрацией по жанрам
- Карточка книги с кнопками «в избранное» / «забронировать»
- Личный кабинет читателя: избранное, бронирования, выданные книги, история
- Кабинет библиотекаря: выбор пользователя, управление бронями,  выдача, избранные читателя
- Анимации при наведении, оверлей на обложках, карусель на главной
- Интерактивная SVG-карта библиотеки с анимированными элементами
- Адаптивная вёрстка, единый хедер

## База данных

PostgreSQL. Схема — в `database/init.sql`.  
Таблицы: книги, пользователи, библиотекари, избранное, бронирования, выдачи, история.

## Локальный запуск

1. Установить PostgreSQL, создать БД, выполнить `database/init.sql`
2. Перейти в `backend/`, выполнить `npm install`
3. Запустить бэкенд: `npm start` (или `npm run dev`)
4. Открыть `index.html`
